WBD_Draft_Helper

WBD 팀리그 시즌3 드래프트를 위한 감독들이 편하게 선수정보를 찾아보고 포지션, 자기소개 등을 확인하고 직접 설정 선수에 별점을 매겨서 우선순위를 설정하고 드래프트 계획 및 전략을 편하게 구상할수있게 도와주는 프로그램

--------밑은 AI가 써준 소개글------------
WBD 드래프트 헬퍼 + 시뮬레이터
VRChat Baseball Discord (WBD) 커뮤니티의 Season 4 드래프트를 위한 평가/시뮬레이션 도구. 9명의 감독, 100명의 선수, S1~S4 4섹션 드래프트의 입찰·타이브레이크·강등 규칙을 그대로 구현. 단일 HTML 파일이라 다운로드 후 브라우저에서 바로 실행.
주요 기능
드래프트 헬퍼

100명의 선수 카드 (자기소개, 포지션, 시즌별 통계) 기본 제공
별점·메모·태그·즐겨찾기로 개인 평가 기록
타겟 P (입찰 희망가) 설정 및 라운드별 예산 계획
베스트12 슬롯 + 뎁스 차트로 라인업 구상
대체 선수 자동 추천: 한 선수가 픽되면 비슷한 대안을 자동 제시. 균형/포지션 매칭/내 로스터 보완 3가지 모드 지원. 점수 분해 표시로 왜 추천됐는지 한눈에
9감독 픽 현황·예산·픽 로그 사이드바
JSON 가져오기/내보내기로 평가 데이터 백업·공유

드래프트 시뮬레이터

9감독의 각 라운드 입찰 P를 직접 입력하면 규칙대로 자동 처리 (밀봉 입찰, 순서 입찰, 오버플로우, 타이브레이크, 강등까지)
섹션 진행 상황·감독별 잔여 P·픽 카운트 실시간 표시
라운드 진행 중 언제든 드래프트 보드 모달에서 9감독 픽 현황을 라운드×감독 표로 한눈에 확인
헬퍼에서 입력한 선수 데이터(이름·인덱스·포지션·자기소개)가 시뮬레이터에도 자동 반영

사용법

최신 wbd-draft-helper4.html 다운로드
더블클릭으로 브라우저에서 열기 (별도 설치 불필요)
자동으로 100명 + 9감독 기본 데이터 로드. 자동 저장됨
데이터 초기화는 도움말의 "⚠ 전체 초기화" 버튼

데이터 관리

모든 데이터는 브라우저 localStorage에 자동 저장 (LZ-String 압축)
JSON 내보내기 권장: 다른 컴퓨터에서 이어 쓰거나 백업용
SEED_VERSION 마커 방식: 운영자가 SEED를 갱신하면 사용자 컴퓨터에서 자동 반영되되, 감독이 직접 수정한 평가/포지션은 보존됨

기여 (운영자용 SEED 수정)
HTML 파일 안의 const SEED_PLAYERS = [...] 배열을 직접 수정. 수정 후 같은 파일의 const SEED_VERSION = N; 숫자를 1 올리면 다음에 페이지를 여는 모든 사용자에게 자동 반영됨. 빈 필드는 채워지고 감독이 직접 수정한 필드는 보존되는 부분집합 휴리스틱 적용.
기술 스택

단일 HTML, 빌드 단계 없음
Vanilla JavaScript + React (in-browser Babel 변환)
Tailwind CSS (CDN)
LZ-String (localStorage 압축)
